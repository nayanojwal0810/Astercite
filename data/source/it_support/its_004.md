# Approved Software Request Process

## Purpose and Scope
This document outlines the standard procedure for requesting, evaluating, and provisioning software applications and cloud subscriptions across Aster Systems. It applies to staff members and technical teams seeking developer utilities, productivity tools, or specialized applications on company-managed endpoints. Standardized evaluation ensures software acquisitions align with organizational needs and security standards.

## Software Request Approval
Structured review of software requests ensures proper management oversight and departmental budget alignment.
<!-- fact_id: ITS004_F01 -->
Every submitted request requires formal authorization from the applicant's assigned team lead before IT Support initiates procurement or installation. Obtaining manager confirmation ensures requested software directly supports the employee's operational responsibilities.

## Unlisted Software Review
Applications and cloud services that do not currently appear on the pre-approved enterprise catalog require thorough evaluation.
<!-- fact_id: ITS004_F02 -->
For any software application not included on the standard catalog, a security review is required to ensure compliance with enterprise data governance and network isolation standards. Technical assessment mitigates potential security risks before installation.

## Standard Request Processing
Following necessary approvals and reviews, IT Support fulfills requests by deploying software packages or assigning user licenses.
<!-- fact_id: ITS004_F03 -->
The standard turnaround time to fulfill approved catalog software installations is 3 business days from the date of final approval. This processing window provides support specialists sufficient time to verify packaging, assign licenses, and deploy the application.

## Exceptions and Related Documents
Software packages procured as corporate assets and assigned to workstations adhere to operational asset governance detailed in OPS-005. Furthermore, this procedure receives incoming software provisioning requests originating from remote and hybrid personnel under HR-002.

## Revision History
Version v1 is effective from 2026-11-01. This initial baseline establishes workstation software requisition standards and review procedures.
