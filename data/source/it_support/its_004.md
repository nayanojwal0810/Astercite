# Approved Software Request Process

## Purpose and Scope
This document outlines the standard procedure for requesting, evaluating, and provisioning software applications and cloud tool subscriptions across Aster Systems. It applies to all permanent staff, contractors, and specialized technical teams seeking developer utilities, productivity suites, or SaaS services on company-managed endpoints.

## Software Request Approval
Employees must submit software requests through the internal IT service desk catalog, specifying the required package, installation scope, and business justification.
<!-- fact_id: ITS004_F01 -->
Every submitted request requires formal authorization from the applicant's assigned team_lead before the IT support department initiates procurement or packaging actions. Applications submitted without manager confirmation remain in a pending queue until approved.

## Unlisted Software Review
Applications or cloud services that do not currently appear on the pre-approved enterprise catalog require thorough architectural evaluation.
<!-- fact_id: ITS004_F02 -->
Any software application not included on the standard catalog mandates that security_review_required analysis is performed to ensure compliance with enterprise data governance and network isolation standards.

## Standard Request Processing
Once all necessary authorizations and compliance evaluations are successfully completed, IT support schedules deployment to the target workstation or assigns licensing credentials.
<!-- fact_id: ITS004_F03 -->
The standard turnaround time to fulfill approved catalog software installations is 3 business_days from the date of final approval. Emergency operational tools may be expedited through priority ticketing queues.

## Exceptions and Related Documents
Software packages procured as corporate assets and assigned to workstations adhere to operational asset governance detailed in OPS-005. Furthermore, this procedure receives incoming software provisioning requests originating from remote and hybrid personnel under HR-002.
