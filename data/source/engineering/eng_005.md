# Troubleshooting Known Error Codes

## Purpose and Scope
This troubleshooting guide provides technical diagnosis procedures, recovery actions, and error code interpretations for core microservices and backend components operated by Aster Systems. Standardized remediation steps help on-call responders and software engineers resolve recurring system errors efficiently while protecting downstream service dependencies. This guide applies to all engineering personnel investigating service anomalies and runtime exceptions.

## E1001 Authentication Error
Authentication errors interrupt secure communication between client applications, API gateways, and downstream microservices.
<!-- fact_id: ENG005_F01 -->
Error code E1001 indicates an expired authentication token, requiring the user to sign in again to obtain a valid session credential. Prompt re-authentication restores session authorization and clears downstream gateway rejections.

## E2003 Retry Procedure
Automated client applications and services must follow standard retry procedures when encountering error code E2003.
<!-- fact_id: ENG005_F02 -->
When error code E2003 occurs, wait 60 seconds before retrying the request. Enforcing a retry delay of 60 seconds allows services to recover and prevents automated clients from amplifying system load.

## E3002 Billing Error
Billing transaction workflows involve asynchronous data exchange between internal ledgers and payment processing services.
<!-- fact_id: ENG005_F03 -->
Error code E3002 indicates that billing synchronization is pending across payment processing queues, requiring the responding engineer to check reconciliation status in the payment gateway ledger before taking further action. Verifying the reconciliation status confirms whether automated processing is progressing normally.
